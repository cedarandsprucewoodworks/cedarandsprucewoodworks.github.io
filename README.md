# Cedar & Spruce Handcrafted Woodworks

This repository hosts the Cedar & Spruce Handcrafted Woodworks website.

The site is designed to showcase rustic, handcrafted cedar products made for gardens and outdoor spaces. The current homepage is a temporary landing page, and the preserved full site is available at `full-site.html`.

## Purpose

Cedar & Spruce focuses on:
- Handcrafted cedar planter boxes for herbs, flowers, vegetables, and succulents
- Cedar window boxes for porches, fences, and home exteriors
- Raised garden beds built for durability and long-term outdoor use
- Natural, chemical-free cedar construction that resists rot and insects
- Built in the Webster, NY area

## Site Structure

- `index.html` — current landing page used by the live site
- `full-site.html` — preserved version of the original homepage and product site
- `Assets/` — images and media assets used by the site

## Notes

The full preserved site emphasizes cedar's natural benefits, builder care tips, and custom order process. It is intended as an informational brochure-style website for customers interested in cedar garden products and custom woodworking services.
